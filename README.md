# HEM SmartTrack - Pembentangan Penanda Arasan Amalan Terbaik Sekolah Rendah 2026

**Kategori:** Guru Sekolah Rendah (Hal Ehwal Murid & Kemenjadian Murid)  
**Sekolah:** SK Ranggu, Tawau, Sabah  
**Tajuk Inovasi:** HEM SmartTrack: Pendigitalan Pengurusan HEM Bersepadu Berasaskan Data Masa Nyata  

---

## 🌟 Ciri Utama Slaid Persembahan (Edisi Anugerah Emas TS25)
* **Format:** Web-based Presentation Deck (16:9 Landscape)
* **Animasi:**
  * Zarah emas bergerak (*Floating Gold Particles*) & *Mesh Gradient Glow*
  * Pengiraan nombor dinamik (*Live Number Count-Up Animation*) untuk metrik impak
  * Simulasi pengisian kehadiran langsung dengan pop-up notifikasi dan kemas kini status masa nyata
  * Kesan audio frekuensi lembut (*Web Audio API Synthesizer*)
* **Alat Pembentang:**
  * Teleprompter / Skrip nota pembentang terbina (Tekan kekunci `N`)
  * Pemasa rakaman video 10 minit terbina
  * Mod Skrin Penuh (Tekan kekunci `F`)
  * Eksport ke PDF 16:9 satu klik

## 🚀 Cara Pelancaran (GitHub Pages)
1. Pergi ke **Settings** repositori ini di GitHub.
2. Klik tab **Pages** di menu sebelah kiri.
3. Di bawah bahagian **Build and deployment**:
   * Source: `Deploy from a branch`
   * Branch: Pilih `main` dan folder `/ (root)`
4. Klik **Save**.
5. Sistem akan memberikan pautan langsung anda:  
   `https://<username>.github.io/<repo-name>/`
